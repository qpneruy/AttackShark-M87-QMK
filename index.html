Attack Shark M87 / Xinmeng M87 — QMK & VIA Tri-Mode Firmware

Full open-source QMK & VIA v3 firmware for the Attack Shark M87 (also known as Xinmeng M87) mechanical keyboard powered by SN32F248B + WCH CH582F.

⬇ Download Latest Firmware (.bin & VIA .json) ⭐ View Source Code on GitHub

Key Features

  • Full Tri-Mode Wireless: Wired USB (1000Hz NKRO), 2.4GHz RF, and Bluetooth 5.3 (3 profiles).
  • Out-of-the-box VIA v3 Support: Remap keys, layers, and macros live on usevia.app.
  • Flash Wear-Leveling Protection: In-RAM live RGB adjustments with on-demand EEPROM save (Fn + /).
  • Custom RGB Animations & Zones: Independent control for Keylight, Sidelight, and Lightbar, plus 10-level battery indicator (Fn + B).
